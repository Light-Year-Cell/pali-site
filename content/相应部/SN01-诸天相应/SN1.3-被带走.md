# SN 1.3 被帶走（Upanīyasutta）

**出處**：相應部 · 有偈篇 · 諸天相應 · 蘆葦品第三  
**PTS**：S i 2–3

---

## 一、巴利原文

*（Mahāsaṅgīti 版，CC0）*

```
Sāvatthinidānaṃ. Ekamantaṃ ṭhitā kho sā devatā bhagavato santike
imaṃ gāthaṃ abhāsi–

[天神偈]
"Upanīyati jīvitamappamāyu,
 jarūpanītassa na santi tāṇā.
 Etaṃ bhayaṃ maraṇe pekkhamāno,
 puññāni kayirātha sukhāvahānī"ti.

[世尊偈]
"Upanīyati jīvitamappamāyu,
 jarūpanītassa na santi tāṇā.
 Etaṃ bhayaṃ maraṇe pekkhamāno,
 lokāmisaṃ pajahe santipekkho"ti.
```

---

## 二、漢譯（莊春江譯，參考）

天神：
> 「生命被帶走、壽命是少的，  
> 被帶到老年者的救護所不存在，  
> 觀看這在死亡上的恐怖者，  
> 應該作帶來樂的福德。」

世尊：
> 「生命被帶走、壽命是少的，  
> 被帶到老年者的救護所不存在，  
> 觀看這在死亡上的恐怖者，  
> 期待寂靜者應該捨棄世間物質（餌）。」

---

## 三、逐詞分析

| 巴利詞 | 語法 | 字義 |
|---|---|---|
| **upanīyati** | 動詞，現在式被動（*upa* + √*nī*）| 被帶走、被引向 |
| **jīvitam** | 名詞，主格 | 生命 |
| **appamāyu** | 形容詞，主格（*appa* + *āyu*）| 壽命短少的 |
| **jarūpanītassa** | 形容詞，屬格（*jarā* + *upanīta*）| 被帶到老年者的 |
| **tāṇā** | 名詞，主格複數 | 救護、保護 |
| **pekkhamāno** | 現在分詞，主格（√*pek* = 看）| 觀看著 |
| **puññāni** | 名詞，業格複數 | 福德 |
| **kayirātha** | 動詞，optative（√*kar*）| 應該作 |
| **sukhāvahāni** | 形容詞（*sukha* + *āvaha*）| 帶來樂的 |
| **lokāmisaṃ** | 名詞，業格（*loka* + *āmisa*）| 世間的餌（欲樂） |
| **pajahe** | 動詞，optative（*pa* + √*hā*）| 應該捨棄 |
| **santipekkho** | 形容詞（*santi* + *pekkhā*）| 期待寂靜者 |

**天神 vs 世尊的差異**：
- 天神勸以**福德**（*puññāni*）回應死亡的恐怖；
- 世尊提升到更高層次：應**捨棄世間欲樂**（*lokāmisaṃ pajahe*），期待真正的寂靜（*santipekkho*）。

---

## 四、義注（Sāratthappakāsinī）

義注（SA）解釋「被帶走」（*upanīyati*）：

生命不斷被引向死亡，就像太陽一旦升起便趨向落下，
任何生命都只是走向終點的旅程。

**「被帶到老年」**（*jarūpanīta*）：
- 老年將人帶向衰敗，使身心的防護失去。
- 「救護所不存在」（*na santi tāṇā*）：財富、親人、權力，均無法阻擋老死。

**天神的建議 vs 世尊的修正**：
- 義注指出，天神建議「作福德」是對在家信眾而言的善建議；
- 世尊則對修行者說更深的話：捨棄一切世間餌食（欲貪），朝向涅槃寂靜。

---

## 五、復注（Sāratthappakāsinī-ṭīkā）

「*lokāmisa*」（世間之餌）：
- 復注解釋，「餌」（*āmisa*）比喻欲望如同魚餌，看似甜美，實則是致命的陷阱；
- 就像魚因貪餌而被釣，眾生因貪欲而繫縛於輪迴。
