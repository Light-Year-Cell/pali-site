# SN 1.3 被带走（Upanīyasutta）

**出处**：相应部 · 有偈篇 · 诸天相应 · 芦苇品第三  
**PTS**：S i 2–3

---

## 一、巴利原文

*（Mahāsaṅgīti 版，CC0）*

```
Sāvatthinidānaṃ. Ekamantaṃ ṭhitā kho sā devatā bhagavato santike
imaṃ gāthaṃ abhāsi–

[天神偈]
"Upanīyati jīvitamappamāyu,
 jarūpanītassa na santi tāṇā.
 Etaṃ bhayaṃ maraṇe pekkhamāno,
 puññāni kayirātha sukhāvahānī"ti.

[世尊偈]
"Upanīyati jīvitamappamāyu,
 jarūpanītassa na santi tāṇā.
 Etaṃ bhayaṃ maraṇe pekkhamāno,
 lokāmisaṃ pajahe santipekkho"ti.
```

---

## 二、汉译（庄春江译，参考）

天神：
> 「生命被带走、寿命是少的，  
> 被带到老年者的救护所不存在，  
> 观看这在死亡上的恐怖者，  
> 应该作带来乐的福德。」

世尊：
> 「生命被带走、寿命是少的，  
> 被带到老年者的救护所不存在，  
> 观看这在死亡上的恐怖者，  
> 期待寂静者应该舍弃世间物质（饵）。」

---

## 三、逐词分析

| 巴利词 | 语法 | 字义 |
|---|---|---|
| **upanīyati** | 动词，现在式被动（*upa* + √*nī*）| 被带走、被引向 |
| **jīvitam** | 名词，主格 | 生命 |
| **appamāyu** | 形容词，主格（*appa* + *āyu*）| 寿命短少的 |
| **jarūpanītassa** | 形容词，属格（*jarā* + *upanīta*）| 被带到老年者的 |
| **tāṇā** | 名词，主格复数 | 救护、保护 |
| **pekkhamāno** | 现在分词，主格（√*pek* = 看）| 观看著 |
| **puññāni** | 名词，业格复数 | 福德 |
| **kayirātha** | 动词，optative（√*kar*）| 应该作 |
| **sukhāvahāni** | 形容词（*sukha* + *āvaha*）| 带来乐的 |
| **lokāmisaṃ** | 名词，业格（*loka* + *āmisa*）| 世间的饵（欲乐） |
| **pajahe** | 动词，optative（*pa* + √*hā*）| 应该舍弃 |
| **santipekkho** | 形容词（*santi* + *pekkhā*）| 期待寂静者 |

**天神 vs 世尊的差异**：
- 天神劝以**福德**（*puññāni*）回应死亡的恐怖；
- 世尊提升到更高层次：应**舍弃世间欲乐**（*lokāmisaṃ pajahe*），期待真正的寂静（*santipekkho*）。

---

## 四、义注（Sāratthappakāsinī）

义注（SA）解释「被带走」（*upanīyati*）：

生命不断被引向死亡，就像太阳一旦升起便趋向落下，
任何生命都只是走向终点的旅程。

**「被带到老年」**（*jarūpanīta*）：
- 老年将人带向衰败，使身心的防护失去。
- 「救护所不存在」（*na santi tāṇā*）：财富、亲人、权力，均无法阻挡老死。

**天神的建议 vs 世尊的修正**：
- 义注指出，天神建议「作福德」是对在家信众而言的善建议；
- 世尊则对修行者说更深的话：舍弃一切世间饵食（欲贪），朝向涅槃寂静。

---

## 五、复注（Sāratthappakāsinī-ṭīkā）

「*lokāmisa*」（世间之饵）：
- 复注解释，「饵」（*āmisa*）比喻欲望如同鱼饵，看似甜美，实则是致命的陷阱；
- 就像鱼因贪饵而被钓，众生因贪欲而系缚于轮回。
