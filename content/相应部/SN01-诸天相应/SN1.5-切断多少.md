# SN 1.5 切斷多少（Katichindasutta）

**出處**：相應部 · 有偈篇 · 諸天相應 · 蘆葦品第五  
**PTS**：S i 3

---

## 一、巴利原文

*（Mahāsaṅgīti 版，CC0）*

```
Sāvatthinidānaṃ. Ekamantaṃ ṭhitā kho sā devatā bhagavato santike
imaṃ gāthaṃ abhāsi–

[天神偈]
"Kati chinde kati jahe, kati cuttari bhāvaye;
 Kati saṅgātigo bhikkhu, oghatiṇṇoti vuccatī"ti.

[世尊偈]
"Pañca chinde pañca jahe, pañca cuttari bhāvaye;
 Pañca saṅgātigo bhikkhu, oghatiṇṇoti vuccatī"ti.
```

---

## 二、漢譯（莊春江譯，參考）

天神：
> 「應該切斷多少、應該捨斷多少，且更應該修習多少，  
> 比丘超越多少染著，被稱為『已渡暴流者』？」

世尊：
> 「應該切斷五、應該捨斷五，且更應該修習五，  
> 比丘超越五染著，被稱為『已渡暴流者』。」

---

## 三、逐詞分析

| 巴利詞 | 語法 | 字義 |
|---|---|---|
| **kati** | 疑問詞 | 多少、幾個 |
| **chinde** | 動詞，optative（√*chid*，切斷）| 應切斷 |
| **jahe** | 動詞，optative（√*hā*，捨棄）| 應捨斷 |
| **cuttari** | 副詞（*uta* + *uttari*）| 更進一步、且更 |
| **bhāvaye** | 動詞，optative（√*bhū*，修習）| 應修習 |
| **saṅgātigo** | 形容詞（*saṅga* + *atiga*）| 超越染著者 |
| **oghatiṇṇo** | 形容詞（*ogha* + *tiṇṇa*）| 已渡暴流者 |
| **vuccati** | 動詞，現在式被動 | 被稱為 |

---

## 四、義注（Sāratthappakāsinī）

義注詳細解釋「五個」各指什麼（SA 1:23–24）：

### 4.1 應切斷五 = 五下分結（*pañca orambhāgiyasaṃyojanāni*）

| 結 | 巴利 | 說明 |
|---|---|---|
| 身見 | *sakkāyadiṭṭhi* | 執取五蘊為我 |
| 疑 | *vicikicchā* | 對三寶的懷疑 |
| 戒禁取 | *sīlabbataparāmāsa* | 以戒行為足，執取儀式 |
| 欲貪 | *kāmacchanda* | 對五欲的貪欲 |
| 瞋恚 | *byāpāda* | 瞋怒、惡意 |

此五結繫縛眾生於欲界，須「切斷」（徹底斷除）。

### 4.2 應捨斷五 = 五上分結（*pañca uddhambhāgiyasaṃyojanāni*）

| 結 | 巴利 | 說明 |
|---|---|---|
| 色貪 | *rūparāga* | 對色界的執著 |
| 無色貪 | *arūparāga* | 對無色界的執著 |
| 慢 | *māna* | 比較心、傲慢 |
| 掉舉 | *uddhacca* | 心的散亂 |
| 無明 | *avijjā* | 對四聖諦的無知 |

### 4.3 應修習五 = 五根（*pañcindriyāni*）

信（*saddhā*）、精進（*viriya*）、念（*sati*）、定（*samādhi*）、慧（*paññā*）

### 4.4 超越五 = 五染著（*pañca saṅgā*）

貪染著（*rāgasaṅga*）、瞋染著（*dosasaṅga*）、癡染著（*mohasaṅga*）、慢染著（*mānasaṅga*）、見染著（*diṭṭhisaṅga*）

---

## 五、復注（Sāratthappakāsinī-ṭīkā）

「*cuttari*」（且更）：
- 復注解釋此詞表示，修習五根不僅是補充，而是在切斷和捨斷的基礎上「更進一步」——
  即修道的積極面（培養）vs 修道的消極面（斷除）。

「*oghatiṇṇo*」（已渡暴流者）：
- 此詞呼應 SN 1.1 的主題，說明整個蘆葦品的核心就是「如何渡過四種暴流」。
