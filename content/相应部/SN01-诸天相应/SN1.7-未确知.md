# SN 1.7 未确知（Appaṭividitasutta）

**出处**：相应部 · 有偈篇 · 诸天相应 · 芦苇品第七  
**PTS**：S i 4

---

## 一、巴利原文

*（Mahāsaṅgīti 版，CC0）*

```
Sāvatthinidānaṃ. Ekamantaṃ ṭhitā kho sā devatā bhagavato santike
imaṃ gāthaṃ abhāsi–

[天神偈]
"Yesaṃ dhammā appaṭividitā, paravādesu nīyare;
 Suttā te nappabujjhanti, kālo tesaṃ pabujjhitun"ti.

[世尊偈]
"Yesaṃ dhammā suppaṭividitā, paravādesu na nīyare;
 Te sambuddhā sammadaññā, caranti visame saman"ti.
```

---

## 二、汉译（庄春江译，参考）

天神：
> 「其诸法未确知者们，会被引导到异教，  
> 熟睡的他们未觉醒，是他们觉醒的时候。」

世尊：
> 「其诸法已确知者们，不会被引导到异教，  
> 那些正觉者以究竟智，在不平顺中平顺地行。」

## 三、逐词分析

| 巴利词 | 语法 | 字义 |
|---|---|---|
| **appaṭividitā** | 形容词，主格复数（*a* + *paṭi* + √*vid*）| 未确知的、未如实知的 |
| **suppaṭividitā** | 形容词（*su* + *paṭi* + √*vid*）| 已善确知的、如实了知的 |
| **paravādesu** | 名词，处格复数（*para* + *vāda*）| 在异教（他人的主张）中 |
| **nīyare** | 动词，现在式被动（√*nī*）| 被引导 |
| **nappabujjhanti** | 动词，现在式（*na* + *pa* + √*budh*）| 不觉醒 |
| **pabujjhitun** | 动名词（√*budh*）| 觉醒（的时候） |
| **sambuddhā** | 形容词，主格复数 | 正觉者、已正觉者 |
| **sammadaññā** | 名词，具格（*sammā* + *ñā*）| 以究竟智、以正确的了知 |
| **visame** | 形容词，处格 | 在不平顺中、在崎岖中 |
| **saman** | 副词 | 平顺地、均等地 |

## 四、义注（Sāratthappakāsinī）

义注解释「诸法」（*dhammā*）：
- 此处指**四圣谛**（*catusacca*）——苦、集、灭、道。
- 「未确知」（*appaṭividita*）：未如实了知四圣谛。
- 未知四圣谛的人，容易被各种外道（*paravāda*）引诱，因为没有正确的见地作为指引。

「熟睡未觉醒」（*suttā nappabujjhanti*）：
- 比喻无明之睡，未见法的人如同沉睡者，对生死轮回的真相无知。

「在不平顺中平顺地行」（*visame saman caranti*）：
- 已如实了知四圣谛的修道者，面对世间的不平顺（苦、老、病、死），
  仍能以智慧保持心的平衡，不被动摇。

---

## 五、复注（Sāratthappakāsinī-ṭīkā）

「*paravādesu nīyare*」（被引导到异教）：
- 复注说明，「异教」不仅指外道宗教，也包括各种世俗知见和哲学主张，
  凡是与四圣谛相违的见解，皆属「异教」。
- 没有正见作为基础的人，容易在各种说法之间飘移，无法确立修道方向。
