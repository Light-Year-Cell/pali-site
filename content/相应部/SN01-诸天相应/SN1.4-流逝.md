<span class="il-w"><span class="il-p">Anupubbaṃ jahanti</span><span class="il-gr">动词短语</span><span class="il-g">次第地舍弃</span></span>
<span class="il-w"><span class="il-p">ti</span><span class="il-gr">引语词</span><span class="il-g">——</span></span>
<span class="il-w"><span class="il-p">anupaṭipāṭiyā</span><span class="il-gr">名·具格</span><span class="il-g">依次第</span></span>

- 住于**后年**者，**初、中**二年〔已〕舍〔他〕；

## 三、复注（Sāratthappakāsinī-ṭīkā）

*法护论师（Dhammapāla Thera）造，六世纪。原典：SAPṬ（Be）Accentisuttavaṇṇanā。*

### 3.1 「kāla」的语源 — 时如何「吞噬」诸法

<div class="il">
<span class="il-w"><span class="il-p">Kālayanti</span><span class="il-gr">动·使·现·三复</span><span class="il-g">令消耗</span></span>
<span class="il-w"><span class="il-p">khepenti</span><span class="il-gr">动·使·现·三复</span><span class="il-g">令耗尽</span></span>
<span class="il-w"><span class="il-p">ti</span><span class="il-gr">引语词</span><span class="il-g">——</span></span>
<span class="il-w"><span class="il-p">kālā</span><span class="il-gr">名·主格·男·复</span><span class="il-g">诸时</span></span>
</div>

「**令〔诸法〕消耗、耗尽者**（*kālayanti khepenti*），故名为『时』（*kāla*）。」——此为**语源释**（以 *kal-*「计量／驱使」释 *kāla*）。

复注随即点出「时」的**胜义地位**：

> 「午前等种种时段，**仅是『法之流转』而已**（*dhammappavattimattatāya*），就**胜义**而言实**不存在**（*paramatthato avijjamānāpi*），唯依**世间约定**（*lokasaṅketamatta*）而成立。然而，正因那法之流转**一去不返**（*gatagatāya anivattanato*），〔『时』便〕仿佛在耗尽、消灭着那一一之法，而自己也随着那些法一同流逝（*sayañca tāhi saddhiṃ accentā viya*）。」

复注引《本生》为证：

> 「**时吞噬众生，连同〔它〕自身的一切**。」（*kālo ghasati bhūtāni, sabbāneva sahattanā* — Jā 1.2.190）

**〔说明〕** 这是全经最深的一笔：所谓「时间流逝」，胜义中并没有一个实存的「时间之流」在外面推着万物——只有**诸法刹那生灭的相续**（*dhammappavatti*）。「时」只是对这相续所安立的**假名**。因此「时吞噬众生」与前经「一心刹那」实是同一义理的两面：所谓被时间带走，就是被自身念念生灭的法所带走。破「实有时间」之执，正与前经破「实有生命体」之执相呼应。

---

### 3.2 「guṇa」义的再辨

复注顺义注所举 *guṇa* 诸义，补充经证并厘清：

<div class="il">
<span class="il-w"><span class="il-p">Vayoguṇā</span><span class="il-gr">名·主格·男·复</span><span class="il-g">年龄之积聚</span></span>
<span class="il-w"><span class="il-p">ti ettha</span><span class="il-gr">处所语</span><span class="il-g">于此中</span></span>
<span class="il-w"><span class="il-p">koṭṭhāsā</span><span class="il-gr">名·主格·男·复</span><span class="il-g">部分／段</span></span>
<span class="il-w"><span class="il-p">guṇā</span><span class="il-gr">名·主格·男·复</span><span class="il-g">即 guṇa</span></span>
</div>

「此处『vayoguṇā』中的 *guṇa*，取『**段／部分**』（*koṭṭhāsa*）〔累积成堆聚〕之义——即初、中、后三期年岁**逐段积聚**的整体。」复注并补举 *guṇa* 的其他用法：**利益义**（*ānisaṃsaṭṭha*，如 Buddhavaṃsa「著树皮衣得十二倍〔功德〕」）、**赞叹义**（*pasaṃsaṭṭha*，如「大仙无数名号，皆依其德而立」Dhs-a）、以及「**倍增／即彼性**」义（*tabbhāvavutti*，如「我当作双倍，倍倍增长」）——以见 *guṇa* 一词随文取义之广，而本经唯取「积聚」。

---

### 3.3 「初」字之意 — 逝年不返；钝根／中根分释三句

<div class="il">
<span class="il-w"><span class="il-p">paṭhama·ggahaṇaṃ</span><span class="il-gr">名·主格·中</span><span class="il-g">「初」字之取用</span></span>
<span class="il-w"><span class="il-p">vayassa</span><span class="il-gr">名·属格·男</span><span class="il-g">年龄的</span></span>
<span class="il-w"><span class="il-p">gatassa</span><span class="il-gr">PPP·属格·男</span><span class="il-g">已逝的</span></span>
<span class="il-w"><span class="il-p">apunarāvatti·dassanatthaṃ</span><span class="il-gr">名·与格</span><span class="il-g">为显示不再回返</span></span>
</div>

「〔义注〕于『初、中年』中特举『**初**』字，是为显示**已逝之年不再回返**（*gatassa vayassa apunarāvatti*）。故〔义注〕紧接着说：『临死刹那，三期尽舍。』」

复注进而疏通**经文与义注的分工**：

> 「巴利经文里，『accenti kālā（时光流逝）』是**总说**时的消逝；为进一步**别显**其相，才又说其余二句（夜催、年舍）。义注则约**钝根者**（*mudindriya*）而说『vayoguṇā 次第舍』〔取粗显易见的年岁变迁〕，约**中根者**（*majjhimindriya*）而说『夜夜催逼』〔取较细的昼夜推移〕，故以『kālā ＝ 午前等时』〔约利根者取最细的时分〕作总收。」

复注末补：义注『午前**等**（*ādi*）』的「等」字，含**午后、初夜分、须臾**（*muhutta*）等更细密的时间区分（*aṇupabheda*）——层层入微，皆是「时」之无常相。

---

### 3.4 「其余」何指

<div class="il">
<span class="il-w"><span class="il-p">Sesan</span><span class="il-gr">形·主格·中</span><span class="il-g">其余</span></span>
<span class="il-w"><span class="il-p">ti</span><span class="il-gr">引语词</span><span class="il-g">——</span></span>
<span class="il-w"><span class="il-p">idha</span><span class="il-gr">副词</span><span class="il-g">此处</span></span>
<span class="il-w"><span class="il-p">dvīsu gāthāsu</span><span class="il-gr">名·处格·女·复</span><span class="il-g">于二偈中</span></span>
<span class="il-w"><span class="il-p">pacchimaddho</span><span class="il-gr">名·主格·男</span><span class="il-g">后半</span></span>
</div>

「〔义注所谓〕『其余』，在此指**两偈的后半**（*pacchimaddha*，即『观死→作福／舍饵』二句）。因其义**于此〔前经〕已得**、且**前一经已说**，故〔义注〕仅作**略指**（*atidisita*）而不重释。」

**〔说明〕** 这是注释体例的一处方便：SN 1.3、1.4 两经末句字句相同（乃至天神／世尊的对答结构相同），义注遂在后一经处以「sesaṃ purimasadisaṃ（其余同前）」一笔带过，避免重复。复注则替读者点明「其余」的确切所指与省略之由。

## 四、语法要点

### 4.1 *accenti* — *ati-* + √i（去）的复数现在式

*accenti* = *ati-*（前缀，越过）+ √*i*/*eti*（去、行）→ *acceti* / *accayati*，现在三复 *accenti*，意为「〔时〕越过、流逝」。

<div class="il">
<span class="il-w"><span class="il-p">ati·eti → acceti</span><span class="il-gr">现·三单</span><span class="il-g">越过／流逝</span></span>
<span class="il-w"><span class="il-p">ati·enti → accenti</span><span class="il-gr">现·三复</span><span class="il-g">〔诸时〕流逝</span></span>
</div>

注：同一 *ati-i* 词根另有「征服、超越」与「敬礼、赞赏」义（如 *accaya*「过失／逝去」、*accanta*「究竟」）；义注在此以 *atikkamanti*（越过、过去）定其为「时间流逝」义。连声：*ati* + *e-* → *acce-*。

---

### 4.2 *tarayanti* — √tar（渡）的使役

*tarayanti* 是 √*tar*（渡、越）的**使役**（causative）*tāreti* / *tarayati* 的现在三复，意为「**使〔人〕渡向、催逼〔人〕前行**」。义注以 *sīghaṃ sīghaṃ gamayanti*（急急驱使）释之，正是使役义。

<div class="il">
<span class="il-w"><span class="il-p">tarati</span><span class="il-gr">现·三单·主动</span><span class="il-g">〔自〕渡越</span></span>
<span class="il-w"><span class="il-p">tāreti / tarayati</span><span class="il-gr">现·使役</span><span class="il-g">使〔他〕渡／催逼</span></span>
</div>

**对读 SN 1.1**：同一词根 √*tar*，在〈暴流渡过〉是主动 *atari / tari oghaṃ*「〔世尊自己〕渡越暴流」；在此则转为**使役**「诸夜催人渡向死亡」——从「渡脱」到「被催渡」，一字之转，境界迥异。

---

### 4.3 *vayoguṇā* — 复合词与 *vayas* 的连声

*vayoguṇā* = *vayo*（< *vayas*，年龄、生命期）+ *guṇā*（积聚）。属**依主释**（tappurisa，属格关系：「年龄之积聚」）。

<div class="il">
<span class="il-w"><span class="il-p">vayas + guṇā</span><span class="il-gr">连声</span><span class="il-g">→ vayoguṇā</span></span>
</div>

连声：词干末 *-as* 在浊音前变 *-o*（*vayas-* → *vayo-*），故 *vayas + guṇā → vayoguṇā*。同类如 *manas → mano-*、*tapas → tapo-*。义注辨 *guṇa* 五义而取「rāsi 积聚」，故此复合词义为「初中后逐段累积的年岁」。

---

### 4.4 愿望语气 — *kayirātha* / *pajahe*（同 SN 1.3）

两偈末句核心动词皆为**愿望语气**（Optative）三单，表「应当、宜」：

| 愿望形 | 词根 / 现在式 | 言 | 义 |
|---|---|---|---|
| *kayirātha* | *kar-* / karoti 作 | 为己言（attanopada）| 应作 |
| *pajahe* | *pa+hā-* / pajahati 舍 | 为他言（parassapada）| 应舍弃 |

注：*kayirā* 是 *karoti* 的不规则愿望词干，*kayirātha* 为其为己言三单形；前经义注径以规则形 *kareyya* 释之，可见同义。详见 [[SN01-诸天相应/SN1.3-被带走|SN 1.3 §4.2]]。

---

### 4.5 连声（Sandhi）— 偈颂词界还原

| 原形 | → | 连声形 | 出处 |
|---|---|---|---|
| ati + enti | → | **accenti** | 两偈首句 |
| vayas + guṇā | → | **vayoguṇā** | 两偈次句 |
| loka + āmisaṃ | → | **lokāmisaṃ** | 世尊偈末句 |
| santi + pekkho | → | **santipekkho** | 世尊偈末句 |
