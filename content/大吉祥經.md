# 大吉祥經（Maṅgalasutta）

**出處**：小部《小誦》（Khuddakapāṭha 5）；《經集》2.4（Suttanipāta 2.4）

---

## 天神之問

> **Bahū devā manussā ca, maṅgalāni acintayuṃ;**  
> **Ākaṅkhamānā sotthānaṃ, brūhi maṅgalamuttamaṃ.**

### 逐詞分析

| 巴利詞 | 語法 | 字義 |
|---|---|---|
| bahū | 形容詞，主格複數 | 許多 |
| devā | 名詞，主格複數（*deva*）| 天神 |
| manussā | 名詞，主格複數（*manussa*）| 人 |
| ca | 不變詞 | 和、與 |
| maṅgalāni | 名詞，業格複數（*maṅgala*，中性）| 吉祥之事 |
| acintayuṃ | 動詞，不定過去時，第三人稱複數（√*cint*）| 思量、考慮 |
| ākaṅkhamānā | 現在分詞，主格複數（*ā*+√*kaṅkh*）| 希求著 |
| sotthānaṃ | 名詞，屬格複數（*sotthi*）| 安樂、吉祥 |
| brūhi | 動詞，命令式，第二人稱單數（√*brū*）| 請說！ |
| maṅgalam | 名詞，業格單數 | 吉祥 |
| uttamaṃ | 形容詞，業格單數 | 最上的 |

### 直譯

「許多天神和人，思量著吉祥之事；希求著安樂，請說最上的吉祥。」
